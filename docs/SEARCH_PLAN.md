## 2. Time resolution

CONTINUOUS INGESTION IS MANDATORY; windowed sampling is quantitatively dead. Intercept probability for an event of duration T s under k non-overlapping windows of w s per day: P = min(1, k*(w+T)/86400); expected catches/yr E = N*P at N events/yr; mean wait to first intercept = 1/(N*P). Table (N = 10 events/yr; event classes: 1-s entry transient, 2-min fast transit, 13-min slow transit): [scheme | duty | P(1 s) / P(2 min) / P(13 min) | E per yr | wait for 2-min transit] -- (a) CURRENT 60 s/day snippet | 0.07% | 7.1e-4 / 2.1e-3 / 9.7e-3 | 0.007 / 0.021 / 0.097 | ~48 YEARS; (b) 60 s hourly | 1.7% | 0.017 / 0.050 / 0.233 | 0.17 / 0.50 / 2.3 | ~2 yr; (c) 10 min hourly | 16.7% | 0.167 / 0.200 / 0.383 | 1.7 / 2.0 / 3.8 | ~6 months; (d) continuous | 100% | ~1 x uptime x (1 - blind fraction) | ~N | within-year. Worse than the raw numbers: intercept is not detection — a partial overlap breaks the doublet template (slam + t_p up to 0.55 s + ring) and the NULL-CLAIM VALIDITY rule requires the FULL event window (slam + t_p + up to 1000-s quench) inside coverage, which windows shorter than ~17 min can never guarantee; scheme (c) intercepts a 13-min transit it can never fully contain. So: full-coverage streaming of all 144 x 10-min MARS files/day (already built) + continuous OOI LF. PROCESSING LADDER (per MARS file): Tier LF — decimate 256 kHz to 200 Hz (0.08% of volume; matches OOI band): entry thump, pinch ring, cavity-pulsation lines, N-waves; 1-10-s FFTs, 50% overlap, 0.1-1 Hz resolution. Tier MF — decimate to 8 kHz: DEMON demodulation, 10-30 Hz hiss AM sidebands, sub-4-kHz combs; reassigned STFT with 0.1-1 s adaptive windows, 75% overlap, so 4-300 Hz/s Doppler chirps do not smear. Tier HF — full 256 kHz: impulse/transient chain, kurtosis, cepstral PRI, envelope at 1-ms resolution for the ms-scale slam rise; analysis in 60-s windows with 10-s overlap so no doublet (max internal lag ~1.5 s) straddles a boundary. EVENT-TRIGGERED EXPANSION: every doublet candidate auto-opens a 1000-s quench watch (D4) and captures +/-30 s of raw waveform for per-pulse cepstra (D6). Cross-site absolute time alignment <=0.1 s (MARS-OOI); 5-ms relative within the OOI GPS network. Continuous per-band ambient statistics and the injection blind-period ledger run alongside, because every null claim must cite them.

## 4. Coincidence / anti-coincidence catalogs

- Lightning: NOAA GOES GLM gridded lightning (public), WWLLN (research access), Blitzortung (community), Vaisala GLD360 (commercial, optional upgrade for ~1-5 km / <1 ms precision). Gate: stroke within 20 km and +/-2 s travel-time corrected -> kill.
- Bolides/fireballs: NASA CNEOS fireball catalog (public JSON API), CTBTO IMS infrasound bulletins (vDEC research request), American Meteor Society + Global Meteor Network reports. Gate: energy-time-position consistent infall -> kill (and calibrates our E_ac ~ 1e-4 x KE anchor).
- Reentries/splashdowns: Space-Track TIP decay messages (free account), Aerospace Corp CORDS reentry predictions, FAA licensed launch/reentry schedules, SpaceX manifests + booster/Dragon-trunk splashdown NOTAMs. CRITICAL for the SoCal Bight sites: Vandenberg boosters and trunk debris produce genuine entry-doublet-class events near the Channel Islands — this join must run BEFORE any CI candidate escalates.
- Vessels/surveys: AIS — NOAA MarineCadastre historical archive (public, US waters) for retrospective joins; aisstream.io (free) for live; kinematic kills at <=15 m/s track match and 2-3 m/s lawn-mower geometry. Survey-twin kill: UNOLS ship schedules + R2R rolling-deck repository + USGS/BOEM seismic-survey permits identify airgun/sparker/sub-bottom operations by cruise.
- Seismic: USGS ComCat + ISC bulletin with T-phase travel-time prediction (+/-30 s, back-azimuth 10 deg); also the plane-wave kill feed for D7 supersonic trace candidates.
- Navy range activity (no public SCORE/SOAR schedule exists — use proxies): FAA NOTAMs for W-291/W-237/W-72 warning-area activations, USCG Local Notices to Mariners exercise/hazard notices, NMFS incidental-take annual monitoring reports (after-the-fact sonar activity summaries), and — found in this design pass — the SanctSound project's own published per-site ACTIVE SONAR and EXPLOSION detection event catalogs for the Channel Islands (NCEI/ERDDAP, e.g. SanctSound_CI03_05_sonar, SanctSound_CI03_06_Explosions): a ready-made labeled interferer ledger for exactly our highest-priority proximity site.
- Aircraft: ADS-B historical archives (OpenSky research API, ADSB-Exchange) for the 13.3-deg air-coupling cone, Lloyd-mirror surface-racer kills, and supersonic-corridor booms.
- Instruments/infrastructure: OOI/ONC/MBARI mooring and asset metadata (clock-grade PRI, fixed carriers at 38/70/120/200 kHz), deployment logs for the artifact kill.
- Biologic template library (internal catalog, same join machinery): sperm-whale 2-9 ms cepstral IPI, beaked-whale FM replica bank (r>0.9), delphinid terminal-buzz ICI convergence, fin-whale 23-18 Hz downsweep + winter seasonality, snapping-shrimp Poisson IEI + static bearing, fish diel/spawning choruses.
- Escalation rule: every candidate must be joined against ALL applicable feeds; one positive join kills; a candidate escalates only after surviving at least two independent kill attempts with all joins returning null (D10).

## 5. Compute budget

One-year FULL-COVERAGE search of the top site (MARS, 256 kHz): FILES 144/day x 365 = 52,560 ten-min files. VOLUME 46 MB/60 s x 525,600 min/yr = 24.2 TB/yr egress (anonymous open-data S3, no egress fee). WINDOWS 60-s analysis windows with 10-s overlap (50-s hop) = 1,728/day = 630,720/yr. CPU at our measured throughput 6 s per 60-s window per core including fetch (real-time factor 0.1): 630,720 x 6 s = 3.78M core-s = ~1,050 core-h; add ~20% for event-triggered reprocessing (1000-s quench watches, +/-30-s waveform cepstra) and ongoing injection calibration -> ~1,250-1,300 core-h = 52 core-days: ~39 h wall on a 32-core node, ~6.5 days on 8 cores; live keep-up needs only ~0.1 core sustained, so a 4-core box runs MARS live monitoring with 10x headroom plus OOI. STORAGE stream-and-discard raw; persist the 200-Hz LF tier (~19 GB/yr), the 8-kHz MF tier (~750 GB/yr raw, ~350 GB as FLAC), event snippets + ambient statistics (<100 GB/yr) — ~0.5 TB/yr retained. ADD-ONS: OOI LF 5-station network is negligible — ~126 GB/yr raw (miniSEED ~40-60 GB), full-network TDOA cross-correlation scan <50 core-h/yr; OOI 64-kHz broadband ~2 stations adds ~6 TB/yr and ~260 core-h (scales with bandwidth, fetch-dominated). Retrospective SanctSound CI01-05 scan (proximity site, ~2018-2021): targeted +/-7-day windows around documented 2019 event dates cost <10 core-h; the full ~10-12 site-year archive at 48 kHz is ~2,500-3,500 core-h and ~10-15 TB if run as a population-bound campaign — schedule it second. TOTAL year-one program (MARS full year + OOI LF + targeted CI windows): ~1,400 core-h and ~25 TB moved — small enough that COVERAGE, exactly as the spec demands, is no longer the binding constraint; the binding constraints become detector build-out (the Doppler ridge tracker and doublet detector) and the catalog join layer.
